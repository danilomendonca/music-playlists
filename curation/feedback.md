# Listening feedback

This log records first-hand listening feedback. Review the [taste profile](taste.md) for guidance that carries across playlists.

## How to add feedback

Use natural language in the Music project. A playlist name and a track name are enough to start. A reason, comparison, or recording detail helps if you have one. For example: “In After Hours, I like the space in this performance, but I'd skip this version in a quieter set.”

Add a dated entry for each listening round. Preserve the playlist context and distinguish a track or recording reaction from a comment on sequencing or fit. Summarize music-related details suitable for this public repository. If the user changes their mind, add a dated correction linked to the earlier entry.
